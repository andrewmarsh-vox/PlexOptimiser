# Ruby — Plex Optimiser

by Andrew Marsh

Optimises a Plex library for **direct play** — so clients stream the file as-is instead
of making the server transcode it — without giving up resolution or quality.

Built for an Intel N100 (Alder Lake-N) running Plex on Ubuntu, where the iGPU is the
only encoder available and is shared with Plex's own transcoding.

---

## What it does

For every file in the library it probes the stream and looks for three independent
reasons to touch it:

| Reason | Trigger | Action |
| --- | --- | --- |
| **shrink** | Bloated high-bitrate remux (≥28 Mbps at 4K, ≥18 Mbps at 1080p) | Re-encode to HEVC via VAAPI |
| **codec** | Video codec clients can't direct-play (`vc1`, `mpeg2video`, `av1`, `mpeg4`, …) | Re-encode to HEVC at native resolution |
| **audio** | No TV-friendly audio track present (`aac`/`ac3`/`eac3`/`mp3`) | Add AC3 5.1 + AAC 2.0 alongside the lossless original |

A file needing *only* audio work is handled in **remux mode** (`-c:v copy`) — zero
video quality loss. TV libraries are additionally capped at 1080p.

Every file is processed **verify-then-replace**: encode to NVMe scratch → verify
duration, codec, track count and size → atomically rename into place → delete the
original. The original is never removed until a verified replacement exists, so an
interrupted run costs scratch work, never a source file.

After each replace it triggers a path-targeted Plex partial scan, so Plex's database
picks up the new codec. Without that, Plex keeps the *old* codec cached and builds a
transcode against a file that no longer matches — playback fails with
"Conversion failed" even though the file is perfectly fine.

## Components

| File | Role |
| --- | --- |
| `ruby.sh` | Main optimiser. Scans, decides, encodes, verifies, replaces, notifies Plex. |
| `ruby-governor.sh` | Plex-first resource governor. Duty-cycles Ruby's cgroup against live iGPU load so Plex streams always win. |
| `ruby-music.sh` | Music pass: converts incompatible audio formats to FLAC, writes ReplayGain 2.0 tags via `rsgain`. |
| `dashboard.py` | Stdlib web UI on `:8800` — progress, per-file plan, live encode telemetry, settings form. PAM-authenticated. |
| `rescan.sh` | Regenerates `state/plan.tsv` read-only, then kicks the optimiser for newly-added files. |
| `status.sh` | CLI progress/control. |

## The governor

The N100 has **one** iGPU, shared between Plex's hardware transcoding and Ruby's
encoding. The governor polls Plex for active sessions and measures real iGPU busy%
from the RC6 residency counter, then applies AIMD to a duty-cycle target:

- Plex idle → **100%** (saturating the GPU is the goal; the encode *is* the load)
- Plex active → iGPU >95% → back off 20 points; <85% → recover 10 points

It throttles by rapidly `SIGSTOP`/`SIGCONT`-ing the service cgroup, which is lossless
to an in-flight encode.

## Install

```sh
git clone git@github.com:andrewmarsh-vox/PlexOptimiser.git /home/naboo/ruby
cd /home/naboo/ruby
cp ruby.conf.example ruby.conf          # then tune, or edit live at :8800
sudo cp systemd/*.service systemd/*.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now ruby.service ruby-governor.service ruby-dashboard.service
sudo systemctl enable --now ruby-rescan.timer ruby-music.timer
```

Requires `ffmpeg` with VAAPI, `intel-media-va-driver-non-free` (iHD), `python3`,
`curl`, and `rsgain` for the music pass.

Libraries and their Plex section IDs are discovered from the Plex API at startup;
the hardcoded `ROOTS`/`PLEX_PATHMAP` are only a fallback for when Plex is unreachable.
The Plex token is read at runtime from Home Assistant's `secrets.yaml` — no credential
is stored in this repo.

## Runtime state

Everything under `state/` is machine-local and gitignored:

- `done.list` — processed files (resume point)
- `converted.tsv` — durable per-file ledger: `ts mode orig new delta dest`. Original
  size is only knowable at conversion time, so this is the authoritative record of
  all-time space reclaimed; it survives plan rescans.
- `plan.tsv` — full library plan, regenerated by `rescan.sh`
- `pending/` — verified replacements staged mid-swap on a full drive; replayed by
  `recover_pending()` on the next start

## Hard-won notes

Things that cost real debugging time on this platform:

- **`-nostdin` is mandatory.** Without it, ffmpeg inside the `while read` scan loop
  inherits the `find` pipe as stdin and reads binary paths as interactive keystrokes.
- **Never use `ffprobe -of csv=p=0` for single-value captures.** It appends a stray
  trailing comma on *some* files, which silently broke 10-bit/HDR detection and nearly
  encoded an HDR remux as 8-bit SDR. Use `-of default=nw=1:nk=1`.
- **This iGPU supports ICQ rate control only on the 10-bit Main10 path.** 8-bit Main
  returns `-22`; it needs `CQP` plus an explicit `-vf scale_vaapi=format=nv12`.
- **Passing explicit `-color_*` flags to the 8-bit Main encoder also returns `-22`**,
  so SDR colour is deliberately left unspecified.
- **`ffmpeg -progress` is block-buffered** — `out_time` can look frozen for 15–20s on
  a perfectly healthy encode. Don't diagnose a wedge from a short poll.
- **Scope `pkill` carefully.** `pkill -f ruby.sh` matches the live service's own
  ExecStart process. Use `systemctl stop ruby`.
